## About Canvas Draw

Canvas Draw is a small, web-based drawing tool centered on the HTML canvas element. Instead of installing a separate desktop program, you get a dedicated space for drawing inside a browser tab.

It is aimed at people who need a no-frills canvas drawing tool: quick sketches, experimentation, or lightweight artwork made in the browser. Because it is delivered as a web application, it works in any compatible browser and keeps the focus on the act of drawing itself.
